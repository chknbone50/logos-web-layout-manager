# Privacy Policy — Logos Web Layout Manager

**Effective date: September 25, 2026**

Logos Web Layout Manager is a browser extension designed to save, manage, and restore workspace layouts in Logos Web.

## Information Handled by the Extension

The extension stores information necessary to provide its layout-management features, including:

- Logos Web workspace URLs and saved layout states
- User-assigned layout names
- Layout protection settings
- Extension preferences
- Recently closed workspace state used for session recovery

This information is stored locally using browser extension storage.

## Data Collection and Transmission

Logos Web Layout Manager does not operate a developer-controlled server and does not transmit saved layout information to the developer.

The extension does not include advertising, analytics, or behavioral tracking.

The extension does not sell user data or transfer user data to third parties.

## Export and Import

Users may voluntarily export their saved layouts to a JSON file for backup or transfer between supported browsers.

Users may also voluntarily import a compatible JSON backup.

These actions occur only when initiated by the user.

## Website Access

The extension's website access is limited to Logos Web at `https://app.logos.com/*`.

This access is necessary for the extension to identify, save, manage, and restore Logos Web workspace states.

## Remote Code

The extension does not execute remotely hosted JavaScript or WebAssembly. Extension code is packaged with the extension.

## Changes to This Policy

This privacy policy may be updated if the functionality or data practices of Logos Web Layout Manager change.
